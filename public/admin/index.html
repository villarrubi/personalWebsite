A tu manera.

Crea, edita y elimina los proyectos del portfolio. Cada cambio se guarda en GitHub y la web se publica sola en unos minutos.

Cómo conseguir el token (solo la primera vez)
  1. Abre GitHub → Fine-grained tokens ↗.
  2. En Repository access elige Only select repositories y marca personalWebsite.
  3. En Permissions → Contents elige Read and write. Opcional: Actions → Read-only para ver el estado de publicación.
  4. Genera el token, cópialo y pégalo aquí.

El token sólo se envía a GitHub. Si no marcas «Recordar», se borra al cerrar la pestaña.
